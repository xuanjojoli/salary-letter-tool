# salary-letter-tool# 批量信件生成工具（调薪信 / 晋升信 / 录用信 通用）

一键把 Excel 员工数据按指定模板批量生成 PDF，每人一份。无需写代码，换场景时在界面上改几处即可复用。

## 能做什么

- 读 1 份 Excel（员工编号、姓名、部门、各类薪资、生效日期、**模板编号**等列）
- 根据「模板编号」列自动选择对应 `.docx` 模板（文件名含编号，如 `模板1.docx`）
- 把整行字段填充进模板（占位符 `{{字段名}}`，字段名 = Excel 表头）
- 每个员工导出 1 个 PDF，按命名规则命名
- 全部输出到同一文件夹

## 目录结构

```
salary-letter-tool/
├── salary_tool.py      # 主程序（双击/命令行运行）
├── make_sample.py      # 生成示例数据与模板，用于快速验证
├── requirements.txt    # 依赖清单
├── build_exe.bat       # 打包成 exe 的脚本
├── configs/            # 场景配置（自动创建，每个 .json 是一个场景）
└── README.md
```

## 一、本地运行（需 Python 3.11）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. （可选）生成示例文件快速验证
python make_sample.py

# 3. 启动
python salary_tool.py
```

## 二、打包成 exe 给同事（同事无需装 Python）

同事电脑只需装 **MS Office Word**（用于转 PDF）。

```bash
# 双击 build_exe.bat，或命令行执行：
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name "SalaryLetterTool" --hidden-import "win32timezone" salary_tool.py
```

打包后 `dist\SalaryLetterTool.exe` 就是绿色单文件程序，直接发给同事双击即可。
`configs/` 场景文件夹会自动生成在 exe 同级目录，可随 exe 一起分发或手工编辑。

## 三、使用方法

1. **选场景**（可跳过）：顶部下拉框可加载/保存/删除场景。不同信件各存一个场景，一键切换。
2. **选文件**：选择 Excel 数据源、Word 模板文件夹、输出文件夹。
3. **选工作表**：若 Excel 有多个 sheet，选对那个。
4. **模板编号列名**：填 Excel 里指定模板的那一列表头（默认自动猜「模板编号」）。
5. **命名规则**：默认 `{员工编号}_{员工姓名}_2026 salary review letter`，用 `{字段名}` 引用任意 Excel 列。
6. **日期格式**：Excel 日期按此格式化（默认 `%Y-%m-%d`，如 `2026-07-01`）。
7. 点 **预览校验**：会列出模板匹配、字段缺失、重名等所有问题，确认无误后再生成。
8. 点 **开始生成**：完成后点「打开输出文件夹」查看 PDF。

## 四、重要约定（换场景时只需保证这几点）

1. **Word 模板占位符写法**：`{{字段名}}`，如 `{{员工姓名}}`、`{{生效日期}}`。
   - 字段名必须与 **Excel 表头完全一致**。
   - 占位符请在 Word 里**一次性连续输入**，不要在中间换字体/改格式，否则可能被拆成多段导致识别失败。
   - 建议模板里只出现「这一份模板用到的字段」，多余的字段不会报错但会渲染为空。
2. **模板文件命名**：文件名里带编号，如 `模板1.docx`、`模板2.docx` … `模板10.docx`。
   编号 `1`、`01`、`1.0` 都会视为同一个编号。
3. **Excel 第一行是表头**，表头不能重复；空行会自动跳过。
4. **每行必须有「模板编号」列的值**，且该编号在模板文件夹里有对应文件，否则该行会被跳过并写进日志。

## 五、常见问题

| 现象 | 原因 / 解决 |
|------|-------------|
| 提示「无法启动 Microsoft Word」 | 本机没装 MS Office Word，或 Word 未激活；装好 Word 再试 |
| 转 PDF 报「命令失败 / 发生意外 / -2146824090」 | Word 没登录激活（Office 365 需先手动打开 Word 登录账号），或文件处于「受保护的视图」——对压缩包/文件夹右键→属性→勾选「解除锁定」，并在 Word 里手动「另存为 PDF」验证能成功 |
| 生成的 PDF 里字段是空的 | 模板占位符名和 Excel 表头不一致，或用「预览校验」看字段缺失提示 |
| 占位符没被替换 | 占位符在 Word 里被拆成多段（改过格式/字体），重新连续输入一遍 |
| 提示「模板编号 X 没有对应模板」 | Excel 里的编号在模板文件名里找不到，检查编号是否一致 |
| 打包后 exe 很大 | 正常，pywin32 / lxml 体积较大；单文件启动稍慢属正常 |
| 想改「2026」 | 改「命名规则」里的文字即可，例如 `{员工编号}_{员工姓名}_2027 salary review letter` |

## 六、新增一个场景（零代码）

例如要做「晋升信」：

1. 准备好晋升信的 Word 模板（占位符 `{{字段名}}` 与晋升 Excel 表头一致）。
2. 在界面里重新选择：晋升 Excel、晋升模板文件夹、输出文件夹。
3. 改「模板编号列名」为晋升 Excel 里对应的列，改「命名规则」为晋升信文件名。
4. 顶部「另存为」场景，起名「晋升信件」。
5. 以后切回「调薪信件」或「晋升信件」只需下拉选择。
